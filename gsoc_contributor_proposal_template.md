# Project Proposal

## 1. Project Title

Provide a short and clear title along with the mentor name.

Example
`Transparency Logs for RubyGems.org` - Mentored by @xyz

---

# 2. Project Size

Choose one:

* Small (~90 hours)
* Medium (~175 hours)
* Large (~350 hours)

Explain **why this scope is appropriate** for the project.

---

# 3. Project Length

Specify the proposed coding period.

Typical durations:

* Small projects: **8–12 weeks**
* Medium/Large projects: **10–22 weeks** (default is ~12 weeks)

Mention any scheduling constraints (exams, internships, etc.).

Example:

> Medium project (~175 hours) over 12 weeks.

---

# 4. Abstract

A short summary of the project (3–5 sentences).

Explain:

* What the project is
* Why it matters
* What the final result will be

---

# 5. Problem Statement

Describe the problem your project solves.

Explain:

* What exists today
* Limitations or issues
* Why this problem matters to the Ruby ecosystem

---

# 6. Proposed Solution

Describe your technical approach.

Include:

* Architecture overview
* Key components
* Implementation strategy
* Technologies or libraries involved

Diagrams or pseudo-code are encouraged.

---

# 7. Project Deliverables

Describe **clear expected outcomes**.

Examples:

* Implement feature X
* Integrate with system Y
* Provide documentation
* Add test coverage
* Release working prototype or production implementation

---

# 8. Timeline / Milestones

Provide a **week-by-week or milestone timeline**.

Example:

### Community Bonding

* Study codebase
* Discuss architecture with mentors
* Finalize project design

### Phase 1

* Implement core functionality

### Phase 2

* Integrate with existing systems
* Write tests

### Phase 3

* Optimization and improvements
* Documentation

### Final Phase

* Stabilization
* Final evaluation and submission

---

# 9. Related Work

Show that you understand the ecosystem.

Include:

* Existing tools or approaches
* Prior related work
* Alternatives and trade-offs

---

# 10. Previous Contributions

Provide links to:

* GitHub contributions
* Pull requests
* Open source projects
* Relevant technical work

Contributions to Ruby projects are strongly encouraged.

---

# 11. About You

Tell mentors about yourself.

Include:

* Background
* Programming experience
* Ruby experience
* Why you want to work on this project

---

# 12. Availability

Mention:

* Weekly availability
* Exams or other commitments
* Any expected breaks during the program

---

# 13. Communication Plan

Explain how you plan to communicate with mentors.

Examples:

* Weekly progress updates
* GitHub issues / PRs
* Discord or mailing list discussions

---

# 14. Additional Notes (Optional)

Anything else mentors should know.

---
